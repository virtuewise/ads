# 01 — Product Overview & Personas

**Status: 🟡 (v0.1 — editor shell + engine real; media import pending) · Code: `apps/electron`**

> Virtue Studio is a **local, engine-driven motion-design application**. It looks and feels like an
> IDE for video: menu bar, tool rail, canvas, node graph, code editor, and a keyframe timeline — all
> backed by a single deterministic project document that both a human and an AI agent can edit.

---

## What the product is

Two sentences:

1. **It is an editor.** You scrub a timeline, drag clips, trim them, drop effects on a stack, lay
   keyframes on tracks, and watch the canvas update live.
2. **It is a program.** Every one of those actions mutates a `ProjectDocument` JSON tree. The same tree
   can be written by hand, generated by a script, or produced by an AI agent — and the app renders it
   identically either way.

The editor is **genre-aware**: choosing a genre (3D/CGI, Narrative, Corporate, Explainer, Documentary,
Detective) reconfigures the smart-cut profile, the keyframe presets, the template library, and the
pipeline shown to the user.

---

## Who it is for

### Persona 1 — The Human Editor

A creative professional — editor, colorist, motion designer, compositor — who wants:

- A tool that **respects judgement**: performance selection, invisible cutting, misdirection, tension
  pacing.
- **Immediate feedback**: transform fields drive the canvas; the preview matches the export.
- **No cloud round-trips**: everything is local and instant.
- **A look they enjoy**: the deep-ink interface (`#07090d` ink, `#ff5a2c` accent, `#5eead4` cool), real
  icons, IDE-grade layout.

They enter through the UI — see [16-INTERFACE](16-INTERFACE.md). They think in shots, beats, and
emotion, and the genre presets are vocabulary for that thinking.

### Persona 2 — The AI Agent Operator

An autonomous or semi-autonomous agent that must:

- Take a **brief** (objective, service, audience, duration, format) and produce a deliverable.
- Work at **scale**: dozens of variants, transcripts, cutdowns, aspect-ratio derivatives.
- Be **auditable**: every decision should be a readable, diffable delta to a project file.
- Never guess the edit structure — **apply a genre pipeline** that already encodes the conventions.

They enter through the **project format + scripting API**, not the UI — see
[05-PROJECT-FORMAT](05-PROJECT-FORMAT.md), [08-SCRIPTING-API](08-SCRIPTING-API.md), and the operating
guide [17-AI-AGENTS](17-AI-AGENTS.md). Their power is bulk assembly and consistency; their weakness is
taste — which is why the human editor has the final pass, and why the shared contract (the project
document) is human-readable.

### Persona 3 — The Contributor

Extends the engine: adds a node, a genre template, an encoder path, a render pass. Enters through
[02-ARCHITECTURE](02-ARCHITECTURE.md) → [03-ENGINE-CORE](03-ENGINE-CORE.md) →
[19-QUALITY-AND-TESTS](19-QUALITY-AND-TESTS.md).

## The dual-door model

This is the product's defining structure. Keep it in mind in every doc.

```
                 ┌──────────────────────────────┐
   Human  ──────►│   The UI (16-INTERFACE)      │
   editor        │   menus · timeline · nodes   │
                 └──────────────┬───────────────┘
                                │  mutates
                                ▼
                 ┌──────────────────────────────┐
   AI     ──────►│   ProjectDocument (.vfxproj) │◄──── git diffable
   agent         │   composition · timeline ·    │
                 │   graph · effectsStack        │
                 └──────────────┬───────────────┘
                                │  compiles
                                ▼
                 ┌──────────────────────────────┐
                 │   DAG → WGSL → WebGPU         │
                 │   viewport == export          │
                 └──────────────┬───────────────┘
                                ▼
                     system FFmpeg → SSD
```

## Scope boundaries

**In scope:** local editing; six genres; WebGPU compositing; node + code programmability; deterministic
project documents; local FFmpeg export; brand enforcement; agent automation.

**Out of scope:** cloud rendering; user accounts; a general-purpose "any NLE project" importer; static
deliverables; shipping native codec add-ons (we use the system FFmpeg binary instead — see
[07-EXPORT-PIPELINE](07-EXPORT-PIPELINE.md)).
