# Security Policy for Virtue Studio

## Reporting Security Vulnerabilities

We take security seriously. If you discover a security‑related issue in **Virtue Studio**, please help us resolve it responsibly by following these steps:

1. **Do not disclose publicly** – avoid posting details about the vulnerability in public issue trackers, forums, or social media.
2. **Privately report** the issue:
   - **Email**: send a detailed report to `security@virtuewise.com`.
   - **GitHub Security Advisories**: if you have a GitHub account, you can open a private security advisory by navigating to the repository’s **Security** tab → **Security policy** → **Report a vulnerability**.
3. **Include the following information** in your report:
   - A clear description of the vulnerability and its impact.
   - Steps to reproduce the issue (including any relevant code snippets or configurations).
   - The version or commit SHA where the issue was observed.
   - Any suggested mitigation or fix (optional).
4. **We will acknowledge** receipt of your report within 48 hours and keep you updated on the resolution progress.

## Public Disclosure

Once the vulnerability has been resolved, we will publish a public advisory with details of the fix and recommended upgrade steps. Until then, the report will remain confidential.

## Scope

This policy applies to all code and assets in the `virtuewise/ads` repository, including but not limited to:
- Source code in all packages.
- Build scripts, CI/CD configurations.
- Documentation and example assets.

## Security Team

You can reach our security team at `security@virtuewise.com` for any questions regarding this policy.
